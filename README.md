## Run locally
Open `index.html` in a browser, or open this folder in VS Code and use Live Server.

## Publish with GitHub Pages
1. Create a **public** repository named `portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Expected URL after successful deployment: https://shivacharan-oss.github.io/portfolio/
